    Module src/ext/static_highlight

    Static syntax highlighting extension for code-to-HTML conversion

    Transforms code snippets into syntax-highlighted HTML with CSS styling without requiring a live editor instance. Uses a simplified DOM implementation to generate standalone HTML output suitable for static content generation, documentation, code export, and embedding highlighted code in web pages. Supports automatic language detection from CSS classes and custom modes/themes.
