    $findColumnPosition

    • $findColumnPosition(
          lineElement: HTMLElement,
          screenColumn: number,
      ): { node: Node; offset: number; overflow: number }

      Finds the position of a specific column within a line element.

      This method traverses the text nodes within the given line element to locate the node and offset corresponding to the specified screen column. If the column exceeds the total length of the text, it returns the last node and its length.

      Parameters

      • lineElement: HTMLElement

        The DOM element representing the line of text.

      • screenColumn: number

        The target column position within the line (0-based).

      Returns { node: Node; offset: number; overflow: number }

      An object containing the text node and the offset within that node corresponding to the column position, or null if no nodes are found.

    $measureLineToColumn

    • $measureLineToColumn(lineElement: HTMLElement, screenColumn: number): number

      Measures the horizontal position (in pixels) of a specific screen column within a given line element. This method calculates the pixel offset from the left edge of the text layer's container to the specified column.

      Parameters

      • lineElement: HTMLElement

        The DOM element representing the line of text.

      • screenColumn: number

        The screen column index to measure.

      Returns number

      The horizontal position (in pixels) of the specified column relative to the left edge of the text layer's container. If the position cannot be determined, it falls back to an approximation based on the character width.

    getRects

    • getRects(
          startScreenPos: { column: number; row: number },
          endScreenPos: { column: number; row: number },
      ): any[]

      Calculates and returns an array of rectangles representing the visual positions of a range of text between two screen positions within a text layer.

      Parameters

      • startScreenPos: { column: number; row: number }

        The starting screen position of the range.

        • column: number

          The column index of the starting position.

        • row: number

          The row index of the starting position.

      • endScreenPos: { column: number; row: number }

        The ending screen position of the range.

        • column: number

          The column index of the ending position.

        • row: number

          The row index of the ending position.

      Returns any[]

      An array of rectangle objects representing the visual positions of the text range. Each rectangle object contains:

      • left {number}: The left offset of the rectangle relative to the text layer.
      • width {number}: The width of the rectangle. If an error occurs or the line element is not found, a fallback rectangle is returned based on character width and column positions.
